Microsoft Azure Cloud Native Production Architecture

FinShield is designed to deploy across Microsoft Azure services using modular Infrastructure-as-Code (infra/main.bicep):

Azure Data Lake Storage

ADLS Gen2 with hierarchical namespaces enabled. Separates raw immutable applications from curated feature assets.

Azure ML v2 Pipeline

Automated orchestration of data contract validation, feature transformations, GBDT training, and 3-fold probability calibration.

Zero-Idle Cost Compute

Configured with minNodeCount: 0. Virtual machines automatically scale down after 120s of inactivity ($0/hr when idle).

Automated Azure Deployment Steps

# 1. Create Resource Group
az group create --name rg-finshield-prod --location eastus

# 2. Deploy Cloud Resources via Bicep Template
az deployment group create --resource-group rg-finshield-prod --template-file infra/main.bicep

# 3. Trigger Azure ML Training Pipeline Job
az ml job create --file pipelines/pipeline_job.yaml --resource-group rg-finshield-prod
